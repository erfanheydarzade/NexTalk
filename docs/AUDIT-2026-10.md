# Audit notes (October 2026)

Fixed in this tree:
| Severity | Issue | Fix |
|---|---|---|
| High | `verifyHash` computed a hash and discarded it, so tampered native/WASM extensions still ran | `verifyInstalled` pins sha256(len+manifest+len+entry) at install, fails closed (also for installs without a pin), runs exactly the verified bytes; tests in `internal/transport/integrity_test.go` |
| Medium | Extensions inherited the host environment; stderr buffer unbounded | allowlisted env (`PATH`, `HOME`, temp/system vars, `NTX_*`), 64 KiB stderr cap |
| Medium | Chat history, extension state (mailbox read secrets) stored as plaintext in localStorage | stored only inside the AES-GCM vault; legacy keys purged on load |
| Medium | Messenger could not run extensions (`ntx-host.js` never loaded/registered) | loaded + registered after the wasm boots |
| Medium | Tailwind CDN script (unused) and Google Fonts on a key-handling page | removed; CSP with per-script hashes (`web/tools/seal-csp.mjs`) |
| Medium | Auto-check toggle was a no-op (polling removed) | adaptive polling restored (4-30 s, 60 s hidden, back-off) |
| Medium | Go WASM host wrote all call arguments to the same address when a module has no `ntx_alloc` | bump allocation + call lock |
| Low | PBKDF2 310k; raw peer id in HTML; plain-http relay URLs; release workflow shell injection via `inputs.version`; release omitted messenger/host/extensions | 600k (old vaults upgrade on unlock); escaped; https-or-localhost only; env-based inputs; bundled |
| Low | `ntxhost_test.go` did not compile (CI red) | fixed; round-trip test now runs the real shipped extension |

Verified: all 14 Go module hashes in `go.sum` match upstream tags (incl. the nanopack pseudo-version).

Known limitations (not changed):
* WASM extensions run on the page's main thread: a hostile extension can freeze the tab (no timeout). Install only reviewed packages; compare the displayed SHA-256.
* `transport/worker.go` sends signed read requests in the URL query and the signature covers only `pubkey:timestamp`; make sure the server enforces a short window and does not log query strings.
* The Router/shard server is not in this repository and was not tested.
* The test-only hand-assembled queue module in `internal/transport/wasm_queue_test.go` drops frames of ~200-5000 bytes; the shipped extension does not (swept 1 B-5 kB). Root cause not investigated.
* The Proxy tab in the messenger is a stub.
